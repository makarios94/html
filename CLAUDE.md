# AssetLink project

## Delivering documents
- Show every Markdown (`.md`) or PDF (`.pdf`) deliverable in the conversation, every time one is created or meaningfully updated, without being asked:
  - Send the file with `SendUserFile` using `display: "render"` so it opens in the viewer.
  - For `.md` files, also paste the full content into the reply.
- This repo is public. Save deliverables containing internal AssetLink data (pricing, customers, market sizing, roadmap) to the scratchpad, never the repo.
